# References

The implementation supplied with this project is based on the following source papers.

1. Jun Dai, Yanyang Gao. **YOLOv11n-CDL: accurate and lightweight pavement defect detection
   via enhanced multi-scale attention and feature fusion.** Journal of Civil Engineering
   and Management, 2026, 32(1), 119–132.
   DOI: https://doi.org/10.3846/jcem.2026.26166

2. Xuefang Zheng, Lifang Chen, Jiechi Zhang. **TinyDark-YOLO for adaptive and lightweight
   object detection in low-light conditions.** Scientific Reports, 2026.
   DOI: https://doi.org/10.1038/s41598-026-58443-9

The project uses the CDL architecture as the main detector modification and incorporates
the AGE idea from TinyDark-YOLO as an extension. The notebook additionally tests a
brightness-gated AGE variant (R5).
